# Caso de prueba de cruzar_citas.py (citas_ventana)

Caso sintético para pruebas/probar_limites.py. Las referencias solo sirven para
probar el cruce; no es un texto académico.

## Cuerpo

Según el IPCC, el calentamiento continúa, como muestra Pérez (2021) para la región.

El IPCC y Pérez (2021) coinciden en el diagnóstico.

Con datos del IPCC, Sexto Informe de Evaluación (2021), se estima el balance (IPCC, 2021).

## Referencias
