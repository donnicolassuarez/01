# SLIDE 13 - TIPNIS: CONTEXTO HISTÓRICO

**Título (48-52px):**
```
TIPNIS 2011: El Caso que Puso a Prueba el Convenio
```

**Pregunta (32-40px, destacada):**
```
¿Qué era TIPNIS?
```

**Contenido (28-32px):**
```
Territorio Indígena y Parque Nacional Isiboro Sécure (TIPNIS)

• Territorio: Ubicado entre departamentos de Beni y Cochabamba

• Pueblos: Tsimane, Moxeño, Yuracaré

• Área: 1.2 millones de hectáreas (uno de los más biodiversos)

EL PROYECTO (lo que pasó):
• Gobierno propuso construir carretera Villa Tunari - San Ignacio

• La carretera atravesaría directamente el TIPNIS

• Sin consulta previa a los pueblos indígenas
```

**Imagen:** `slide-13-mapa-tipnis.svg` (lado izquierdo)

# SLIDE 14 - TIPNIS: LA VIOLACIÓN DE DERECHOS

**Título (48-52px):**
```
La Violación de Derechos (2011)
```

**Contenido (28-32px):**
```
• NO hubo Consulta Previa: Los pueblos no fueron consultados

• Marcha Indígena: 500 km a pie, agosto-octubre 2011

• Represión en Chaparina: Enfrentamiento con policía, muertos y heridos

• Proyecto Suspendido: Por presión internacional y de OI

• Posterior Consulta Rechazada: OIT y CIDH dijeron que fue deficiente

CONCLUSIÓN:
Bolivia incumplió el Convenio 169 que había ratificado
```
