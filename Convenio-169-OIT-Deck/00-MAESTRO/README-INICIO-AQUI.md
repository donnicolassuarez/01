## 🚀 FLUJO DE TRABAJO (3 Pasos Simples)

### **PASO 1: Revisar Contenido**
1. Abre la carpeta **`01-SLIDES-CONTENIDO`**
2. Abre cada archivo `SLIDE-XX-*.md`
3. Aquí están los textos listos para copiar

### **PASO 2: Localizar Imágenes**
1. Abre la carpeta **`02-IMAGENES-URLS`**
2. Busca `IMAGENES-SLIDE-XX.md`
3. Descarga las imágenes usando los links

### **PASO 3: Integrar en Claude Design**
1. Lee **`04-INSTRUCCIONES/WORKFLOW-PASO-A-PASO.md`**
2. Sigue los pasos para crear el deck
3. Usa el **CHECKLIST** para verificar

## 📁 EXPLICACIÓN DETALLADA DE CADA CARPETA

### **📂 01-SLIDES-CONTENIDO/**

**¿Qué es?** Cada slide con su contenido de texto listo para copiar-pegar

**Archivos:**
- `SLIDE-01-Portada.md` - Slide 1 (Portada)
- `SLIDE-02-OIT-Datos.md` - Slide 2 (La OIT)
- `SLIDE-03-OIT-Tripartismo.md` - Slide 3 (Tripartismo)
- ... y así hasta SLIDE-17

**¿Cómo usarlos?**
1. Abre el archivo de la slide que necesites
2. Copia TODO el contenido de texto
3. Pégalo en Claude Design

---

### **📂 02-IMAGENES-URLS/**

**¿Qué es?** Imágenes específicas para cada slide con URLs de descarga

**Archivos:**
- `IMAGENES-SLIDE-01.md` - Imagen para Slide 1
- `IMAGENES-SLIDE-02.md` - Imagen para Slide 2
- ... y así para cada slide

**Información incluida:**
- ✅ Descripción de imagen
- ✅ Link de descarga directo
- ✅ Nombre de archivo recomendado
- ✅ Instrucciones de descarga

**¿Cómo usarlos?**
1. Abre el archivo de imagenes para tu slide
2. Haz clic en el link de descarga
3. Descarga la imagen
4. Sube a Claude Design como "Asset"

---

### **📂 03-REFERENCIAS/**

**¿Qué es?** Documentos de apoyo y referencia

**Archivos:**

- `convenio-169-slides.md` - Versión original en Markdown

**¿Cuándo usarlos?**
- Como referencia si necesitas más detalles
- Si quieres ver todas las URLs juntas
- Para revisar la información original

---

### **📂 04-INSTRUCCIONES/**

**¿Qué es?** Guías paso-a-paso para integrar en Claude Design

**Archivos:**
- `INSTRUCCIONES-CLAUDE-DESIGN.md` - Cómo usar Claude Design
- `WORKFLOW-PASO-A-PASO.md` - Flujo completo (LEER ESTO)
